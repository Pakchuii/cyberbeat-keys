## 📖 项目简介 (Introduction)

**CyberBeat Keys** 是一款专为二次元、音游玩家（Arcaea / Phigros / osu!mania / DJMAX）以及极简桌搭爱好者设计的 Windows 独立桌面挂件。

通过 Windows 底层低延迟全局键盘 Hook（C++ 原生守护进程）与纯 GPU 硬件加速 Canvas 渲染引擎，将您的每一次键盘敲击实时映射为**水晶下落 Note、立体 Hold 激光柱、霓虹判定线脉冲与空灵打击音效**。

无论是日常打字码字、写代码，还是在英雄联盟、FPS 游戏中激战，CyberBeat Keys 都能为您的桌面注入前所未有的视听打击快感！

## ✨ 核心特性 (Key Features)

### 💎 1. Arcaea 专属纯净音游打击流 (Arcaea Rhythm Stream)
- **纯净单点 Note**：单次敲击精准掉落剔透水晶 Note（`note.png`），落点触发璀璨微晶爆破；
- **立体透光 Hold 激光长柱**：长按按键超过 140ms 时，动态延伸出立体光能长条柱（`note_hold.png`）；
- **长按防刷屏去重机制**：长按键位时智能识别并保持激活，杜绝系统键盘自动连发导致的刷屏与噪音；
- **全屏下落 / 上升打击流**：支持经典垂直下落式（Arcaea / osu!mania）与律动上升式（Phigros）随时切换。

### 🎨 2. 12 套二次元与音游专属动态主题 (12 Anime & Rhythm Themes)
- 🕊️ **Arcaea · 光 (Hikari)**：琉璃彼方 · 纯白蓝光与记忆玻璃碎片
- 🥀 **Arcaea · 对立 (Tairitsu)**：猩红深渊 · 裂隙红晶与暗夜黑曜石
- 🌟 **初音未来 (Miku Teal)**：苍绿赛博 · 浮动青色全息音符
- 🌸 **魔法少女 (Sakura Pink)**：唯美飘逸落樱花瓣与粉霞
- ⚔️ **明日方舟 (Arknights Tech)**：战术机能工业金菱形晶体
- 🌌 **蔚蓝档案 (Blue Archive)**：圣三一青空羽毛与战术光环
- 💜 **EVA 初号机 (EVA Purple)**：暴走紫绿蜂巢能量力场
- 🔥 **原神 · 炽热火神 (Pyro Flame)**：燃烧烈焰火星微粒
- ⚡ **Phigros 官方霓虹 (Phigros Neon)**：电离几何打击多边形
- 🌊 **鬼灭之刃 · 水之呼吸 (Water Wave)**：湛蓝水珠涟漪律动
- 🪐 **崩坏：星穹铁道 (Star Rail)**：银河星穹闪烁轨迹
- 🦇 **东方 Project · 红魔馆 (Touhou Scarlet)**：暗夜红月与蝙蝠流光

### 🎹 3. 17 款高保真旋律乐器与打击音效库 (17 Soundpacks + Custom)
- **音游/空灵乐器**：Arcaea 纯净玻璃音、治愈八音盒、空灵竖琴、清脆水滴、二次元 Pop、复古 8-Bit 街机、马林巴木琴、赛博晶体合成器、Lo-Fi 钢琴等；
- **真实机械键盘**：HiFi 麻将音（Mahjong Thock）、清脆机械青轴、圣熊猫轴；
- **自定义音频导入**：支持一键导入任意 `.mp3` / `.wav` / `.ogg` 本地音频文件作为专属击键音；
- **动态音调调制**：快速击键时音调动态自然爬升，充满律动感。

### 🪟 4. 全透明悬浮桌搭与自由尺寸拉伸 (Custom Layout & Resize)
- **自由缩放与拖拽**：关闭鼠标穿透后，按住右下角手柄可**任意自由拉伸长宽比**，位置与尺寸自动记忆保存；
- **鼠标完全穿透 (Click-Through)**：开启后鼠标点击完全穿透挂件，不影响游戏操作、码字或日常办公；
- **横向 / 竖向双形态**：支持横向经典桌面长条、竖向侧边音游瀑布流；
- **自定义壁纸裁剪**：支持导入本地插画壁纸，自由调节透明度、缩放比与 XY 坐标偏移。

### ⚙️ 5. 极致系统集成与轻量优化 (System Integration)
- **一键挂件显隐**：在设置中心或托盘菜单随时切换显示/隐藏，无需频繁开关软件；
- **开机自启动**：内置 Windows 系统级自启动注册与 Startup 快捷方式双重保障；
- **超低资源占用**：空闲与打字状态 CPU 占用均 `< 0.5%`，纯 GPU 加速，支持 144Hz+ 高刷显示器。

## 🚀 快速上手与运行 (Quick Start)

### 方式一：直接下载运行编译好的绿色版 (Recommended)
直接在 [Releases](https://github.com/Pakchuii/cyberbeat-keys/releases) 页面下载 `CyberBeatKeys.exe` 单文件绿色便携版，双击即可直接运行，无须安装任何运行环境！

---

### 方式二：从源码 Clone 并启动 (Developer Setup)

#### 1. 克隆代码仓库
```bash
git clone https://github.com/Pakchuii/cyberbeat-keys.git
cd cyberbeat-keys
```

#### 2. 安装依赖项
```bash
npm install
```

#### 3. 启动开发模式
```bash
npm start
```

---

## 🛠️ 打包与编译 (Build Instructions)

本项目支持一键打包为 Windows 独立绿色单文件 EXE：

```bash
# 重新编译 C++ 全局键盘监听底层 (可选，默认已内置编译好的 hook.exe)
npm run build:hook

# 打包为 Windows 独立 Portable 单文件绿色版 EXE
npm run build:exe
```

打包完成后，可执行程序将生成在 `dist/` 目录下。

## 📂 项目架构与目录结构 (Project Architecture)

```
cyberbeat-keys/
├── build/                      # 应用程序图标与打包资源
│   ├── icon.ico                # Windows 应用图标
│   └── icon.png                # PNG 高清图标
├── native/                     # 原生 Win32 键盘 Hook
│   ├── hook.cpp                # C++ WH_KEYBOARD_LL 底层高性能全局钩子源码
│   └── hook.exe                # 预编译的高性能键盘监听守护进程 (< 95KB)
├── src/
│   ├── main/                   # Electron 主进程
│   │   ├── index.js            # 窗口生命周期、托盘菜单、IPC 通信调度
│   │   ├── hookManager.js      # 原生键盘 hook 子进程监管与事件管道
│   │   ├── configStore.js      # 用户配置持久化模块 (JSON 存储)
│   │   └── preload.js          # 安全上下文隔离与 API 暴露
│   └── renderer/               # 渲染层 (纯 GPU 硬件加速)
│       ├── overlay.html/js     # 桌面全透明挂件主视图与 144FPS 渲染循环
│       ├── settings.html/js    # 赛博朋克设置中心 (主题/音频/壁纸/挂件控制)
│       ├── assets/             # 静态资源
│       │   ├── arcaea/         # Arcaea 官方质感贴图 (note.png, note_hold.png 等)
│       │   ├── css/            # 界面样式
│       │   └── icons/          # 系统托盘与界面图标
│       └── engine/             # 核心引擎驱动层
│           ├── rhythmKeyEngine.js # 物理键位映射、Note 下落、立体 Hold 激光柱引擎
│           ├── audioEngine.js     # Web Audio API 极低延迟多复音音效合成与采样引擎
│           ├── particleEngine.js  # 二次元粒子/落樱/星尘/晶片物理爆炸系统
│           ├── comboEngine.js     # 实时 WPM 测速与 Combo 连击状态机
│           └── judgmentEngine.js  # PURE / FAR 音游判定动画引擎
├── .gitignore                  # Git 忽略配置
├── LICENSE                     # MIT 开源许可证
├── package.json                # 项目依赖与构建脚本
└── README.md                   # 项目说明文档
```

## ⌨️ 快捷操作指南 (Shortcuts & Tips)

| 操作 | 功能说明 |
| :--- | :--- |
| **双击托盘图标** | 快速打开 / 唤出【设置中心】 |
| **右键托盘图标** | 快速切换主题、一键显隐挂件、切换穿透状态、退出程序 |
| **拖拽挂件主体** | 在关闭鼠标穿透状态下，按住挂件任意位置自由拖拽移动 |
| **拖拽右下角手柄** | 在关闭鼠标穿透状态下，按住挂件右下角三角形手柄自由拉伸长宽比 |
| **长按键盘按键** | 长按 > 140ms 触发立体 Hold 激光光柱 |
